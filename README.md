# 海螺游学 · 考研数学自适应刷题工具

面向考研数学的轻量 PWA：每日一练、章节讲义、错题本、记忆曲线复习、限时模拟考，全部在本地完成，不需要账号。

## 覆盖科目

| 科目 | 章节数 | 知识小节 | 题量 |
| --- | --- | --- | --- |
| 数学一 | 20 章 | 76 | 580 |
| 数学二 | 12 章 | 44 | 593 |
| 数学三 | 15 章 | 49 | 582 |
| 396 经济类联考 | 10 章 | 31 | 530 |

题库共 2285 道已审核题目，每个知识小节都有题；每章配「考点 + 公式 + 方法 + 易错点 + 例题精讲」讲义。

## 功能

- **今日一练**：按错题、久未复习、新题加权组卷，题型轮换（选择 → 填空 → 解答），同题不重复，首页显示倒计时与今日进度
- **学习中心**：章节 / 小节两级导航，讲义逐章阅读，标记已学，显示每章已练题数与正确率
- **做题体验**：选择题点选即判、填空题回车提交、支持「不会直接看答案」，交卷前展示标准答案与完整解析、易错点
- **错题本**：错误 / 不会 / 部分正确自动收录，可按章节、结果、错因筛选，重做答对自动移出
- **记忆曲线**：按 1 / 2 / 4 / 7 / 15 / 30 天排期复习，答对拉长间隔，答错回到第 1 天
- **模拟考试**：10 / 15 / 20 题限时客观题，交卷二次确认、时间到自动交卷、成绩归档与逐题解析
- **搜题**：按题干、解析、答案、章节或讲义内容检索，可直接看解析或练本章
- **我的**：设置初试日期、每日题量、主题（跟随系统 / 浅色 / 深色）、字号，导出 / 导入 / 清空进度，安装到主屏幕
- **PWA**：离线可用、有新版本时提示刷新，PNG 图标（含 maskable 与 iOS 主屏幕图标）

## 技术说明

- 纯 HTML / CSS / 原生 JavaScript（经典脚本，无框架、无构建步骤），零运行时依赖
- `core.js` 为纯逻辑（组卷、判分、答案归一化、复习调度），可在 Node 中直接单测
- `app.js` 负责状态、路由与视图；每个页面都是「纯函数 → HTML 字符串」，可在 Node 中渲染做冒烟测试
- 进度保存在浏览器 localStorage；页面切换使用 History API，安卓返回键 / 浏览器后退可逐页返回
- Service Worker：导航网络优先（保证更新）、脚本样式与题库 stale-while-revalidate、图标缓存优先
- `server.mjs` 是本地静态服务器：gzip、ETag/304、缓存头、路径越界拦截

## 本地运行

```bash
node server.mjs          # http://127.0.0.1:4173
```

任意静态服务器也可以，但需要支持 `.webmanifest` 的 MIME 类型。

## 测试与构建

```bash
npm test        # 核心逻辑 + 题库质量门禁 + 全部页面渲染冒烟
npm run build   # 生成可部署的 publish-site/
```

- `test-core.mjs`：组卷、判分、答案等价、复习调度、难度筛选
- `test-data.mjs`：题库结构与答案、重复题、选项、章节覆盖、组卷不重复
- `test-views.mjs`：14 个页面在 Node 中渲染，检查关键元素、转义与 undefined/NaN

## 题库维护

```bash
npm run data:fix   # 去重、修错题、统一答案写法、补齐空档小节
npm run icons      # 重新生成 PNG 图标（需要 Python + Pillow）
```

题库生成脚本在 `tools/gen-*.mjs`，清洗与补题脚本在 `tools/fix-bank.mjs`、`tools/patch-gaps.mjs`。改完题库务必跑 `npm test`。
