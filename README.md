# 海螺游学 · 考研数学自适应刷题工具

面向考研数学备考的轻量 PWA 刷题应用：每日一练、章节讲义学习、错题本、记忆曲线复习、模拟考试，全流程本地存储，无需账号。

## 覆盖科目

| 科目 | 章节数 | 题量 |
| --- | --- | --- |
| 数学一 | 20 章 | 670+ 道 |
| 数学二 | 12 章 | 590+ 道 |
| 数学三 | 15 章 | 590+ 道 |
| 396 经济类联考 | 10 章 | 530+ 道 |

题库内置 2391 道题，覆盖课程表全部知识小节；每章配套「考点 + 公式 + 方法 + 易错点 + 例题精讲」讲义。

## 功能

- **每日一练**：自适应组卷，错题优先、14 天内不重复、题型轮换（选择 → 填空 → 解答），完成后有正确率小结
- **章节学习**：讲义逐章学习，按小节标记已学进度，小节可直达练习
- **错题本**：做错 / 不会 / 部分正确的题自动收录，可筛选章节、结果与错因；重做答对自动移出
- **记忆曲线复习**：按 1 / 2 / 4 / 7 / 15 / 30 天排期复习，答对拉长间隔、答错回到第 1 天
- **模拟考试**：限时客观题成套组卷（10 / 15 / 20 题，难度可筛），交卷自动判分；错题自动进错题本
- **进度备份**：一键导出 / 导入 JSON 进度，换设备或分享均可迁移

## 技术说明

- 纯 HTML / CSS / 原生 JavaScript（经典脚本，无框架、无构建步骤），Service Worker 离线缓存
- 数据保存在浏览器 localStorage，各人进度互不影响
- 核心逻辑与 UI 分离：`core.js` 为纯逻辑模块（可在 Node 中直接单测），`app.js` 负责渲染与交互
