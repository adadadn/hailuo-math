# 考研数学 Viberecoding 里程碑 v0.3

> 文档状态：待 MVP spec 评审  
> 编写日期：2026-09-22

## 里程碑 M1：自适应每日一练 MVP

- **目标**：验证用户能否围绕数学一、数学二、数学三或 396，完成“选择项目和章节、获得个性化题单、作答、对答案、自动打卡”的每日学习闭环。
- **关键卡点**：
  1. 多考试项目和章节能否通过配置管理，而不是复制多套功能。
  2. 历史练习结果能否可靠地驱动下一次每日组卷。
  3. 手机浏览器中的题目阅读、作答和打卡体验能否稳定完成。
- **范围**：
  1. 用户选择数学一、数学二、数学三、396。
  2. 选择或查看对应章节。
  3. 管理带有标准答案、解析和标签的真题、章节模拟题。
  4. 用户设置每日题量，系统按学习状态组卷。
  5. 用户作答、对答案、标记学习结果。
  6. 记录错题与基础学习统计。
  7. 每日一练完成后自动打卡。
  8. 以手机优先的响应式 Web App 交付，并提供添加到主屏幕的 PWA 基础能力。
- **不包含**：
  - AI 临时原创题目并直接作为正式题库内容。
  - 主观题手写步骤的自动、确定性判分。
  - 豆包 App 内运行、账号同步或平台级集成。
  - 社区、排行榜、多人协作、支付和移动端原生 App。
- **验收标准**：
  1. 用户可在数学一、数学二、数学三、396 中切换，且看到各自的章节和题目范围。
  2. 用户可设置当天题量并获得一份题单；题单中的每题都有来源、答案和解析。
  3. 用户提交作答后，客观答案可自动核对；其他题型可手动确认学习结果。
  4. 已确认的错误题会在错题记录中按项目和章节关联保存。
  5. 完成当天题单后，系统自动生成当天打卡记录。
  6. 下一次每日组卷会参考既往题目结果，并避免在短期内重复同一题。
  7. 用户可在主流手机浏览器完成从选项目到打卡的全流程。
- **完成标志**：在可通过手机访问的 HTTPS 测试环境中，用至少两个考试项目、多个章节和一组可用题库数据，完整走通上述流程并通过验收。

## 里程碑 M2：拍照作答与豆包辅助分析

- **目标**：验证作答照片能在用户确认下辅助对答案，而不阻塞基础练习闭环。
- **范围**：相机/相册上传、图片存储、豆包模型/API 调用、识别/分析结果展示、低置信度与失败回退、当天题单基础缓存。
- **验收标准**：用户上传一张作答照片后，能看到模型调用状态和辅助分析结果；无论模型成功与否，都可以手动确认结果并完成当天打卡。

## 里程碑 M3：微信小程序发布

- **目标**：在微信内提供已验证的每日练习闭环，降低考生的移动端使用门槛。
- **范围**：微信小程序前端、微信登录、服务端接口适配、平台配置、审核与发布。
- **验收标准**：用户能在微信小程序中完成项目选择、每日一练、作答、对答案、打卡和照片上传；其学习数据与 Web 端一致。

## 里程碑 M4：题库与学习反馈完善

- **目标**：扩大题目资产和学习反馈的可用性，使用户能稳定按章节复习。
- **范围**：题目/资料批量导入、错因分类、章节掌握度、复习建议、题目检索、基础趋势统计、提醒能力。
- **验收标准**：用户可定位任意已导入章节的题目与错题，并据此创建或接受复习任务。
